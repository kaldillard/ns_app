# Serene Pulse Design System

## Brand Vision

**Sanctuary** is a premium nervous system regulation app. The **Serene Pulse** design system is crafted to reduce cognitive load and promote immediate physiological calm through minimalist elegance and organic movement.

## Core Principles

- **Minimalist Premium:** Clean, uncluttered interfaces with purposeful whitespace.
- **Organic Movement:** Soft gradients and fluid animations mirroring natural biological rhythms.
- **Scientific Grounding:** UX patterns based on Polyvagal Theory (Ventral Vagal, Sympathetic, and Dorsal states).
- **Tactile Sophistication:** Deep rounded corners (`ROUND_FULL`) and glassmorphism effects.

## Color Palette

The palette uses Sage Green and Soft Teal against warm off-white surfaces to evoke a sense of nature and serenity.

| Token           | Value     | Usage                                                               |
| :-------------- | :-------- | :------------------------------------------------------------------ |
| **Primary**     | `#a8c8b8` | Sage Green - Main brand color, active states, and call-to-actions.  |
| **Surface**     | `#faf9f6` | Warm Off-White - Main background color for a soft, paper-like feel. |
| **Surface-Dim** | `#dbdad7` | Neutral Grey-Beige - Secondary backgrounds and subtle dividers.     |
| **On-Surface**  | `#1a1c1a` | Deep Charcoal - Primary text for high legibility.                   |
| **Secondary**   | `#476557` | Deep Forest - Accents and secondary interactive elements.           |

## Typography

- **Primary Font:** **Manrope**
- **Characteristics:** Modern sans-serif, clean geometry, excellent legibility at all scales.
- **Scale:**
  - **Display:** 32px / Bold (Hero headers)
  - **Headline:** 24px / Semi-Bold (Section titles)
  - **Body:** 16px / Regular (Main content and descriptions)
  - **Label:** 12px / Medium (Small UI elements and navigation)

## Component Patterns

- **Navigation:** Floating pill-shaped bottom navigation with `backdrop-blur-md` (glassmorphism).
- **Cards:** High-radius containers (`rounded-3xl` or `rounded-full`) with subtle organic shadows.
- **Buttons:** Fully rounded pill shapes with gentle transitions.
- **Illustrations:** Minimalist, hand-crafted organic forms with soft gradients.

## Motion & Interactivity

- **Animations:** Fluid, slow-paced transitions.
- **Visual Effects:** WebGL-based shaders for breathing guides to ensure smooth, natural movement.
- **Feedback:** Subtle haptic-inspired visual pulses on interaction.
